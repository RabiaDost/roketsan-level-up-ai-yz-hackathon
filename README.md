# LEVEL-UP AI | ROKETSAN Yapay Zeka Hackathonu — Workshop Calismalari

ROKETSAN ve Coderspace tarafindan duzenlenen LEVEL-UP AI hackathonunun egitim workshop projeleri.

## Projeler

- `gemini-llm-workshop` — LLM / RAG / Agent (MIL-STD dokuman asistani)
- `computer-vision-workshop` — on isleme, siniflandirma, YOLO tespit ve takip

## Kurulum

API anahtarini GitHub'a koyma. `gemini-llm-workshop/.env.example` dosyasini `.env` olarak kopyala ve kendi anahtarini yaz.

```powershell
cd gemini-llm-workshop
copy .env.example .env
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

```powershell
cd computer-vision-workshop
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```
